## 🚀 使用方法

### 基本启动
```bash
# 实时模式（默认）
python scripts/launch_viewer.py --mode realtime --symbol btcusdt

# 历史模式
python scripts/launch_viewer.py --mode historical --file data.csv

# 使用自定义配置
python scripts/launch_viewer.py --config my_config.json
```

### 配置管理
```bash
# 保存当前配置
python scripts/launch_viewer.py --save-config

# 配置文件会自动生成：luminaut_config.json
```

### 配置示例
```json
{
  "app": {
    "mode": "realtime",
    "symbol": "btcusdt",
    "timeframe": "1min"
  },
  "chart": {
    "width": 1400,
    "height": 800,
    "show_toolbar": true
  },
  "indicators": {
    "vwap": {
      "enabled": true
    },
    "sma": {
      "enabled": true,
      "periods": [20, 50]
    }
  }
}
```
